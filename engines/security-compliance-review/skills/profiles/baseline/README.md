# `baseline` profile

Intentionally empty. This profile has no rubric overrides — it is the
framework-neutral compliance floor in `../../base/iac-compliance.md` (CIS
Benchmarks / NIST CSF / OWASP), applied directly with no agency-specific
additions.

It exists as a directory (rather than being the implicit "no profile" state)
so it can be selected explicitly and so it has somewhere to grow into if it
ever needs its own override — see [docs/profiles.md](../../../../../docs/profiles.md).
