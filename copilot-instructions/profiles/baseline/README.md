# `baseline` profile — Copilot instructions

Intentionally empty. This profile has no instruction additions — it is the
framework-neutral set in `../../base/instructions/` (OWASP / CIS / NIST CSF),
synced on its own with no agency-specific overlay.

It exists as a directory so `PROFILE: baseline` is a valid, explicit choice in
the sync workflow and so it has somewhere to grow into if it ever needs its
own additions — see [copilot-instructions/README.md](../../README.md).
