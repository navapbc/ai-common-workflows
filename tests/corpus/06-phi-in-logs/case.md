# 06 — PHI/PII written to application logs

Exercises `code-security.md` step 3A.1 (logging hygiene). SSN, date of birth
and diagnosis into a log line.

The case a pattern matcher handles worst and this review should handle best:
nothing here is syntactically wrong, and the field names carry the whole
signal. It is also the finding a CMS program most needs, which makes it the
first one to check after any rubric edit.
